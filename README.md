# Kaizen Incremental Game

**Kaizen** is a idle game developed to learn Angular's architecture. This project represents my transition from React and Svelte towards a more disciplined, opinionated development approach.

## Project Goals

- **Learning Angular:** Implementing Services, Dependency Injection, Authentication and State-Management
- **Architecture over Chaos:** Trying to implemente Clean, easy to read & refactor Code wherever possible.
- **Professional Standard:** Using GitFlow and Clean-Code Principles

## Tech Stack

- **Frontend:** Angular 21
- **Language:** TypeScript
- **BaaS:** Convex (Real-time Database & functions)
- **Auth:** Clerk
- **Styling:** TailwindCSS
